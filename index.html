      A new network

      The model trained on another network, plus the new network's normal traffic, plus k labelled attack flows from it. Recall at 1% false alarms on the new network.

      Why ToN-IoT is harder

      Same LightGBM runs with 1,000 labels, choosing which flows get labelled. Where "spread over time" wins, the attack changes over time; where even the full training set fails, the flow features cannot separate it.

      How well it works, and how sure we are

      Thresholds are fixed on validation data at 1% false alarms and applied unchanged to later, untouched test traffic at its real attack ratio. Every number below was fixed as a pass test before it was measured.

      What version 2 tested, in order

      Each phase stated its pass test before running. A fail is a hypothesis the data rejected, with the reason measured, not a broken experiment.
